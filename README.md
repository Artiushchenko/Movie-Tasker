# Movie Tasker

A Vue.js application for organizing and managing a personal watchlist of movies and TV series.

## Overview

Movie Tasker allows users to keep track of movies and series, manage their watchlist, and monitor viewing progress through a simple interface.

## Features

- Movie and TV series watchlist
- Viewing progress tracking
- Form validation
- State management
- Toast notifications
- Responsive interface

## Tech Stack

- Vue.js
- Vuex
- Vuelidate
- Vite
- JavaScript
- SCSS

## Getting Started

### Prerequisites

- Node.js
- Yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/Artiushchenko/Movie-Tasker-VUE.git
cd Movie-Tasker-VUE
```

Install dependencies:

```bash
yarn install
```

### Development

Start the development server:

```bash
yarn dev
```

The application will be available at:

```text
http://localhost:5173
```

## Production

Build the application:

```bash
yarn build
```
